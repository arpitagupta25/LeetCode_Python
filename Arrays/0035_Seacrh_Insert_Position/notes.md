# Search Insert Position

## Difficulty
Easy

## Pattern
Biery Search

## Concepts Used

- Array

## Approach

Check if the target element is present in the array. If yes,return the index of element.
If not, then run a while loop, return the index position when the element is greater than the target element.
If the loop variable reaches the end of the array, return the length of array.

## Time Complexity

Overall = O(n)

## Space Complexity

O(1)
